# Adventure Hub reference prototype

This is the **exact user-supplied standalone** `Dinosaur_Horror_Adventure_Hub_Cinematic(1).html`, with one added final newline. The embedded images, CSS, JS, and local demonstration save data are preserved as supplied. It is **not** the production game; it intentionally uses illustrative scenario IDs and simulated saved games, not the RPG engine's authoritative state. No API keys are included.

To open in GitHub Pages after deployment: [cinematic hub demo](./Dinosaur_Horror_Adventure_Hub_Cinematic.html).

Production integration work is tracked in [DHR-073 / issue #126](https://github.com/Diabolicdonut/Dinosaur-Horror-RPG/issues/126) and [009-R2 presentation plan](../docs/PRESENTATION-AND-HUB-ROADMAP.md). Only `src/adventure-hub-catalog.mjs` binds real playable IDs for future hub implementation; standalone demo screens remain unconnected. Do not treat demo JSON or localStorage as Party saves.
