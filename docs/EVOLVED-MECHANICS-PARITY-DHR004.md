# DHR-004 — Evolved Edition mechanics parity evidence matrix

**Audit date:** 2026-11-03. **Issue:** [#70](https://github.com/Diabolicdonut/Dinosaur-Horror-RPG/issues/70). **Source baseline:** main commit a418f72fb4a70562c38ec436ed03b59fc2628ec7 (accepted gameplay 009-D2, v0.7.39; subsequent first-wave integration already on main). **Roadmap target:** gate 7, evolved-full-parity (**partial**). This documentation-only inventory changes no gameplay, saves, checkpoints or accepted 38/100 roadmap score.

## Evidence standard and scope

The primary mechanical authority is the user's **private** Free League *ALIEN RPG — Evolved Edition* reference, in the user's Library. Source locations below are **printed book pages**, cross-checked against that private reference and the existing docs/EVOLVED-RULES-AUTHORITY.md; they are pointers, **not reproduced copyrighted rules, tables or prose**. A repository code path demonstrates what exists; a named test path demonstrates a narrower, repeatable check, **not** the whole rule's correctness or cross-adventure acceptance. The 2019 edition and legacy src/engine.mjs cannot override Evolved rules. Jurassic Park-themed substitutions and deterministic clock conventions remain documented adaptations, not unreported Evolved RAW.

**Status is per precisely described implementation slice, not global readiness:** **implemented** = identified bounded, executable behavior with a regression; **partial** = only a subset, lab-only hook, source-sensitive approximation, or incomplete integration; **missing** = no functional implementation of that mechanic in accepted playable paths. An **implemented** row does not promote the gate to accepted. The Character Lab, legacy Nublar runtime, and selected standalone adventure runtime are different execution paths; no claim that each feature works in all three. “Missing” is a negative code/test audit, not proof that no possible future branch has the feature.

## Post-audit integration reconciliation (2026-11-03)

Following the original DHR-004 snapshot, separate independently verified PRs added bounded supporting components: DHR-009 / [PR #90](https://github.com/Diabolicdonut/Dinosaur-Horror-RPG/pull/90) introduced a **pure, trusted-source-stock-input** ammunition conservation ledger, and DHR-017 / [PR #87](https://github.com/Diabolicdonut/Dinosaur-Horror-RPG/pull/87) introduced an **authoring-only** NPC motive/intent binding. The E21 and E26 evidence rows above now acknowledge these modules; both remain **partial**, with no new runtime offensive attacks, human NPC autonomous combat or accepted weighted roadmap points. No claim of full rulebook/mechanics parity is implied.

## Cross-runtime reconciliation

- **Character Lab:** initial attributes/skills/talents, simulated seeded checks, some stress/Resolve and Story Point hooks. It is not equivalent to full campaign playable advancement.
- **Nublar Party:** separate legacy-compatible party-v3 medical/combat support and source-bounded dinosaur actions. The older solo src/engine.mjs is explicitly **not** an Evolved parity implementation.
- **The Long Count and The Tidal Nursery:** selected adventure packages have real scenario-bound stealth, objectives and localized NPCs. The Long Count has live predator-contact/reaction/combat cases; Tidal Nursery rev2 is peaceful with local NPCs. Neither should be used to imply shared offensive combat or universal Evolved parity.
- **Historical and replay protection:** tests/party-engine.test.mjs, tests/evolved-checks.test.mjs, tests/evolved-injuries.test.mjs, tests/live-research-combat-009b2b2c2c2b.test.mjs, tests/adventure-second-package-009d1.test.mjs and tests/adventure-tidal-npc-009d2.test.mjs cover seeded or preserved paths. These are existing checks; this audit changes none of the relevant sources or historical revision manifests.

## Required next verification before accepting gate 7

1. **Source-to-test traceability:** each implemented mechanic must be associated with the precise Evolved edition page, actor/world preconditions, algorithmic exceptions and tests in the actual runtime(s); lab-only behavior cannot imply cross-adventure parity.
2. **Highest-priority missing rules:** implement source-governed XP/advancement; world-gated Story Point earning/spending and every adopted career talent; reliable panic/stress consequences; eligible helping/gear/difficulty effects; and offensive combat and NPC effects without mixing owned equipment with phantom resources.
3. **Branch and compatibility acceptance:** independently replay old Nublar party-v3, Long Count historical revisions and Tidal Nursery rev1/rev2 saves; compare seeded outcomes, secrecy/control modes and no compulsory creature contact. Review current main immediately before integration because other worker PRs can add new mechanics.
4. **Real-play verification:** finish actual desktop/mobile graphical QA and user-facing narration checks. CI can establish deterministic code behavior, but cannot substitute for this testing.

**Non-adopted source-specific systems:** spacecraft economics/battles, alien biology, android-only mechanics and licensed scenario procedures are not automatically Dinosaur Horror requirements. If any are deliberately adapted later, document the scoped decision and test it. The optional E13 life-path variant is inventory only, not a new acceptance requirement. No rulebook files or verbatim tables belong in the public repository.
