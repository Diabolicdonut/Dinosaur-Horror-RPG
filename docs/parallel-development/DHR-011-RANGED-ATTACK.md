# DHR-011 / Issue #82 — Pure source-bound ranged attack roll

**Worker scope:** a new `src/ranged-attack.mjs` and focused regressions. This is
a **PR-only, unaccepted subtask** of the partial offensive-combat roadmap gate;
accepted roadmap scoring and gameplay release version remain unchanged.

## Mechanical authority and boundary

- Primary source: the user-private *Alien RPG Evolved Edition*, combat pp.
  59–66. Firing a ranged weapon is a full combat action; ordinarily the
  Agility-linked RANGED COMBAT check uses actual base and stress d6, pushes,
  Resolve and conditional existing story-point rules.
- `resolveRangedAttack(state, stock, action, targets)` delegates all dice to
  the existing `resolveSkillCheck`, requires an active human initiative card,
  and uses the same full-action budget as the accepted combat scheduler.
- `state` is the authoritative **candidate world state** with actors, carried
  weapon declarations, ammo ledger, rooms, and combat card/budget.
  `stock` is the **independent authored inventory total** (never read from a
  client-edited save); validated with DHR-009 before any attack dice.
  `targets` must be a **trusted world-derived target roster**, never a target
  list generated by the user/AI. A requested ID absent from this source roster
  is rejected. Each target has `id` and optional factual `dead`/`defeated`.
  The caller must also truthfully filter live scene targets.
- `action` requires `actorId`, `weaponId`, `targetId` and unsigned 32-bit
  `seed`; it may carry `push`, `spendStoryPoint`, `storyPointTiming`.
  No arbitrary modifier, extra gun, alternate skill, aiming or damage claim is
  accepted from the caller.
- Rejected normal attempts return `{accepted:false,reason}` with no RNG
  draw, time, inventory or save mutation. Malformed authoritative inputs and
  forged conserved ammunition raise `RangeError` without mutation.

## Output is a proposal, not a committed hit

A valid roll returns the actual Evolved check journal, copied post-check actor,
proposed post-full-action budget, declared loaded round identity, and a
`{kind:'spend',actorId,weaponId}` transaction descriptor compatible with
DHR-009. Neither a successful die roll nor the descriptor consumes ammunition.
The result intentionally sets `hit:null`, `damage:null` and
`worldEffects:'unresolved'`. A miss still needs a future authoritative
ammunition-spend transaction; a success is **not** a narrative impact.

## Explicit deferred integration

DHR-012 must verify actual range bands, minimum weapon range, line of sight,
partial/full cover, range-specific modifiers, defense declaration/dodge and
possible friendly fire from authenticated positions and weapon statistics.
DHR-013/015 must finalize damage/armor/critical effects, action/event/seed
transactions and appropriate finite-ammo spending (including failed shots) as
one replay-validated atomic world update. This isolated module cannot certify
a physically valid shot before those adapters exist. It deliberately does
not introduce a new gun stat table or guess which weapon can hit at what
distance. The current literal-round DHR-009 ledger is the accepted stock
boundary; Evolved's original supply-die flow remains a separate documented
parity/integration decision.

**No existing source runner, UI, scenarios, save version, adventure
fingerprint, roadmap acceptance files or Game Mother secrecy boundary are
changed.** Manual browser and Cloudflare verification are not claimed.
