# DHR-003 — Adversarial player-view disclosure regression inventory

**Assignment:** [Issue #69](https://github.com/Diabolicdonut/Dinosaur-Horror-RPG/issues/69) — test-only security/privacy contract. **Source baseline:** 009-D2 / v0.7.39; accepted 18-gate score **38/100** unchanged. This note is not a server-secrecy certification or an accepted milestone.

## Trust boundaries and tests

| Surface / adversary | Current behavior and tested invariant | Residual risk |
| --- | --- | --- |
| Fresh Long Count (quiet and predator seeds), Tidal Nursery (several seeds) | Player view includes public place, valid available NPC topics and actor-owned dossier text, not the full GM-only notes, NPC motive or remote NPC entities. Hidden variant at session start is not automatically presented as a known predator. | Seed and full authored sources ship to the browser; inspecting scripts bypasses presentation filtering. |
| Party, Focus and Spectator, including independent camera | Current controlled seat's act agenda and earned story card only. Changing camera does not transfer ownership. Spectator receives no private seat dossier. | The current partyView().actors summary contains **all teammates' positions/health**, even when separated; some UI elements hide details, but the underlying projection is not a fully perception-bound camera view. This is not fixed by this test-only issue; schedule hardening with DHR-071 and engine/UI policy work. |
| Optional scene/handout and local NPC testimony | Reveal requires the genuine source/seed and recorded scene, objective or observed NPC event. Remote NPC conversations are rejected. Forged scene records, NPC placement, conversation history or adventure fingerprint are invalid as authority saves and cannot be projected as validated views. | The lower-level pure playerScenarioMaterial function alone trusts passed records; validate the complete authoritative save before exposing its output. Do not hand raw unverified imported JSON to it. |
| Companions and autonomous proposals | actorObservation feeds an actor-specific observable projection to chooseCompanionAction; same locally invisible seed differences do not change the initial companion decision. | This is not an omniscience-proof guarantee for every future autonomous path. Review new AI contexts separately. |
| Solo model request | Browser gmContext() is built from view(state), not hidden dinosaur state. A mocked real handleRequest ensures an unseen sentinel does not reach the model when the client submits only that observable context. Output schema is typed and mechanically non-authoritative. | **Worker currently forwards authenticated caller-supplied payload fields** within its size/type checks. A compromised/self-modified browser can deliberately transmit private client facts. It is not a trusted server-private GM knowledge boundary. |
| Save export, localStorage and debug | Raw Party save serialization retains real dinosaur positions and event history by design. Debug export explicitly warns it includes full hidden world state; credential/token redaction is separately asserted. | Anyone with browser storage, exported save, debug report, local source or DevTools can inspect hidden data. Do not share debug or save files as a player handout, even if credentials are removed. |
| Historical adventure versions and replay | Frozen Ridge revision 9 and Tidal Nursery revision 1 retain compatible saves and original view bounds; JSON roundtrip and seeded action replay produce identical state and filtered view. | The tests cover representative historical revisions rather than a full migration fuzz campaign (assigned separately to DHR-006). |

## Verification contract

Run node --test tests/player-view-secrecy-dhr003.test.mjs, node --check tests/player-view-secrecy-dhr003.test.mjs, and repository-wide npm test; GitHub Actions must verify the exact PR head after push. This tests existing player-view policy and observed limitations; it does **not** revise gameplay, save schema, seed mapping, accepted adventure fingerprints, source Evolved mechanics, UI deployment, Worker credentials, or roadmap progress.

Manual browser DOM/keyboard and network inspection, secret-custody migration to server storage, threat-modeling authenticated client modifications, and actual external-model behavioral secrecy remain outside this bounded issue and pending subsequent acceptance.
