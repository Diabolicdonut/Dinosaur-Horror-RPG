# Dinosaur Horror RPG — Development Worker Instructions

Before development, inspect the latest main branch, project-state.json, site-progress.json, audit.md, and the authoritative development roadmap.

All development work must use a separate feature branch created from the latest main.

Never push gameplay changes directly to main.

Each worker must commit completed work to its own branch, run applicable tests, and open a pull request.

Do not merge your own pull request unless explicitly authorized under the integration policy.

Do not mark a milestone accepted until its changes are merged and required validation succeeds.

Preserve all previously accepted functionality, save compatibility, and roadmap progress.

The Integration Director is responsible for final acceptance, roadmap synchronization, and resolving conflicts.
